# 🌤️ Weather App with Search History

A complete weather application with built-in search history tracking that saves all your weather searches locally.

## ✨ Features

- **Weather Display**: Temperature, conditions, humidity, wind speed, pressure
- **Search History**: Auto-saves all searches with timestamps
- **Persistent Storage**: Data survives browser restarts using localStorage
- **Quick Re-search**: Click any history item to search again
- **Manage History**: Remove individual items or clear all
- **Location Detection**: Automatic geolocation with fallback
- **Responsive Design**: Works on all devices
- **No API Key Required**: Uses free wttr.in API

## 🚀 Quick Start

1. Download `weather-app.html`
2. Double-click to open in browser
3. Start searching!

## 📖 How to Use

### Search Weather
1. Type city name (e.g., "New York", "Tokyo", "Paris")
2. Click **Search** or press **Enter**
3. Weather displays instantly

### Search History
- **View history**: Scroll to history section
- **Re-search**: Click any city name
- **Remove one**: Click ✕ on any item
- **Clear all**: Click "Clear All" button
- **Check count**: See number in parentheses

### Timestamps
- "Just now" - Less than 1 minute ago
- "5m ago" - Minutes ago
- "2h ago" - Hours ago
- "Yesterday" - Within 48 hours
- "6/27/2026" - Older than 2 days
